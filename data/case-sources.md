# 案例种子来源与核对记录

> 历史记录：本文件描述扩库前的三件人工摘要。当前cases.json已替换为278件官方指导案例发布原文，来源快照、采集结果和停止参照标记见README.md、case-collection.json及case-status.json。以下数量和摘要说明不代表现行库状态。

检索及正文核对日期：2026-11-12。共3条，均为最高人民法院官方发布的指导案例人工摘要，不收录全文。逐一实际请求并读取下列最高人民法院官网详情页的正文，核对标题、发布信息、基本案情、裁判结果、裁判理由及相关法条；未仅凭搜索摘要入库。网页解析结果不完整时，另通过 HTTPS 直接读取同一官方页面的 UTF-8 HTML 正文核对。

## 字段口径

- `date` 采用案例正文括号中明确记载的指导案例发布日；网页刊载日单独记于下文，两者不混用，也不以裁判日代替发布日。
- `court` 与 `case_number` 成对记录摘要所依据的终审实体裁判。C1另外存在最高人民法院驳回再审申请的裁定，另列于下文，不将该裁定号与四川省高级人民法院错配。
- `id` 为本地种子标识，不是案号；`guiding_number` 为指导案例编号，不是案号。案号保持官方正文写法，未擅自添加“最高法”等字样。不能确认的字段应为 JSON `null`；本批指定字段均可确认。
- `text`、`facts`、`holding`、`historical_law_note` 为人工整理。标签仅用于检索，不替代法院原文裁判要点；尤其C2的解除保全不是合同解除。
- 每条均固定标记 `kind: 指导案例摘要`、`doc_type: case`、`retrieved_at: 2026-11-12`、`authority_status: 发布记录，当前参照状态未核验`。
- 本次核验确认的是历史发布记录与所载裁判内容，未完成截至检索日的停止参照、调整、替代或现行法律适用核验，不宣称案例当前有效或当前必须参照。历史法条与发布时的法条对应注释不得直接作为当前案件结论。

## C1：指导案例67号

官方来源：[汤长龙诉周士海股权转让纠纷案](https://www.court.gov.cn/shenpan/xiangqing/27831.html)。页面来源标注为最高人民法院网。

- 正文发布日为2016-09-19；网页刊载日为2016-09-30。JSON取前者。
- “基本案情”核实：6.35%股权、总价710万元、分四期付款；第二期迟延，收到解除通知后补付，后续按期付款，出让人退回款项，股权已变更登记。
- “裁判结果”核实：四川省高级人民法院于2014-12-19作出（2014）川民终字第432号民事判决，撤销一审、确认解除行为无效，并判支付转让款。该法院和案号作为JSON主记录。
- 同段另载：最高人民法院于2015-10-26作出（2015）民申字第2532号民事裁定，驳回周士海再审申请。未将该案号扩写为含“最高法”的版本。
- 摘要限于本案股权分期付款不套用当时合同法第167条的解除规则；没有推导为股权转让合同一律不得解除。
- 历史法律依据：相关法条列合同法第94条、第167条；裁判理由另涉及第60条和当时买卖合同司法解释第38条，均按历史文本记录。

## C2：指导案例166号

官方来源：[北京隆昌伟业贸易有限公司诉北京城建重工有限公司合同纠纷案](https://www.court.gov.cn/shenpan/xiangqing/331171.html)。页面来源标注为最高人民法院。

- 正文发布日为2021-11-09；网页刊载日为2021-11-11。JSON取前者。
- “基本案情”核实：货款诉讼中和解、首期300万元、解除保全、余款未按期支付，另诉80万元违约金。
- “裁判结果”核实：北京市丰台区人民法院于2017-06-30作出（2017）京0106民初15563号民事判决；北京市第二中级人民法院于2017-10-31作出（2017）京02民终8676号民事判决，驳回上诉、维持原判。JSON记录二审法院和二审案号。
- 原货款纠纷（2016）京0106民初6385号仅为背景案号，没有误用为本条和解违约金诉讼的主案号。
- 摘要保留债权人已解除保全、债务人恶意违反和解这一前提，没有推广为违约金不得调减的一般规则。
- 历史法律依据：原案适用合同法第6条、第114条；官方发布文本附民法典第7条、第585条对应说明。该说明仅按2021年发布时注释理解，不视为本次完成了现行适用核验。

## C3：指导案例107号

官方来源：[中化国际（新加坡）有限公司诉蒂森克虏伯冶金产品有限责任公司国际货物买卖合同纠纷案](https://www.court.gov.cn/shenpan/xiangqing/143372.html)。页面来源标注为最高人民法院网。

- 正文发布日及网页刊载日均为2019-02-25。
- “基本案情”核实：2008年石油焦采购、HGI指数32与约定36至46不符、买方请求解除、返款和赔偿；裁判理由核实货物仍有使用价值并能以合理价格转售。
- “裁判结果”核实：最高人民法院于2014-06-30作出（2013）民四终字第35号民事判决。JSON严格保留这一写法，不添加“最高法”前缀。
- 二审撤销一审“宣告合同无效”的判项，改判货款损失1610581.74美元及相应利息、堆存费损失98442.79美元。没有将未构成根本违约误写成没有违约或无需赔偿。
- 本案为涉外货物买卖，公约适用及纽约州法律补充适用有特定背景，不直接移用于所有国内合同。
- 历史法律依据：相关法条列民法通则第145条及公约第1条、第25条；理由按2008年涉外关系发生时的法律确定准据法。摘要保留原判措辞，并区分国内合同效力概念。
