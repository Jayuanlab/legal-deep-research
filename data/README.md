## 案例

从[最高法院指导案例栏目](https://www.court.gov.cn/shenpan/gengduo/77.html)的15页索引取得278件独立发布原文，对应指导案例1—279号中的278件，缺45号。保存裁判要点、基本案情、裁判或执行结果、理由及相关法条；这是指导案例发布文本，不等于原始裁判文书全文。cases.json、case-collection.json、case-download-plan.json 分别保存内容、采集结果和下载计划。

原种子编号C1（67号）、C2（166号）、C3（107号）保留，其余编号为C加1000与指导案例编号之和。多个案号及裁判阶段分别保存，不能确认的主要法院、案号不强行填充。旧 [case-sources.md](case-sources.md) 仅记录最初三件种子案例的整理历史，现行正文和快照以cases.json及采集清单为准。

两份官方公告已核对：

- [法〔2020〕343号](https://www.court.gov.cn/fabu/xiangqing/282441.html)：9、20号不再参照，2021-01-01起。
- [法〔2026〕119号](https://www.court.gov.cn/zixun/xiangqing/508031.html)：123、136、139、204号不再参照，2026-08-15起。

这6件保留在资料浏览中并显示提示，默认排除BM25及向量研究检索。其余案例标为效力未核验，不把未命中公告视为仍然有效。公告快照及对应记录见case-status.json。

## 检索与审计

SQLite documents保存结构化记录，FTS5按中文二元词组检索；vector_chunks按模型身份隔离保存向量及正文起止位置，当前使用阿里云text-embedding-v4。全文按最多1800字符、重叠120字符分片，语义检索选取每件资料最匹配的片段，与BM25通过RRF融合，分别召回4条法条和2件案例。片段编号形如C1001_2，原始资料编号另存parent_id；引用验证针对该精确片段。

资料浏览支持类型、主题、关键词与分页，长案例可展开完整发布原文。/api/health显示数量和向量索引状态，/api/catalog返回规范版本和两类主题。audit_corpus.py离线检查条号连续性、唯一性、来源域名、原始快照和文本哈希，生成coverage.json。

已归档文本不代表完成截至当前日期的全量效力核验。尚未覆盖刑法、行政法全套规范、全部司法解释及全国裁判文书；历史案件的旧法和涉外适用也需逐案判断。模型支持性检查与检索排名不能替代法律适用核查。
